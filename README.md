# Python Learning Repository

Welcome to my Python learning repository.

This repository documents my journey of learning Python from core fundamentals to practical application through real-world projects.

The repository is organized into two major sections:

##  01_Fundamentals

This section covers the essential concepts of Python programming, including:

- Variables
- Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Modules
- Object-Oriented Programming (OOP)
- Exception Handling
- File Handling


These topics provide the foundation required for software development, automation, data analysis, machine learning, and artificial intelligence.

---

##  02_Mini_Projects

This section contains beginner-friendly Python projects that apply programming concepts to solve practical problems.

Projects are designed to strengthen:

- Problem-solving
- Logic building
- Code organization
- File handling
- Object-Oriented Programming
- Python best practices

Each project includes its own documentation and source code.
